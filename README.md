# Selenium Test Automation Framework

## Tech Stack
- Java 17
- Selenium WebDriver 4.x
- TestNG 7.x
- Maven
- Page Object Model (POM)
- Extent Reports 5.x
- WebDriverManager
- Log4j2

## What This Framework Tests
End-to-end automation tests for SauceDemo e-commerce application.
Covers login, product cart, remove from cart, and complete checkout flow.

## Test Cases Covered
- logoutTest
- verifyLoginTest (multiple data sets)
- addProductToCartTest
- removeProductFromCartTest
- completeEndToEndFlowTest
